# 📝 Blog Pessoal

Blog estático construído com **Jekyll**, utilizando o tema `jekyll-theme-hacker`.

O objetivo do projeto é publicar artigos de opinião e reflexões sobre engenharia de software, fundamentos técnicos e uso consciente de IA como ferramenta de crescimento profissional.

---

## 📦 Stack

- [Jekyll](https://jekyllrb.com/)
- Tema: `jekyll-theme-hacker`
- Markdown
- GitHub Pages (opcional para deploy)
